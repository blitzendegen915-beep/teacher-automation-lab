# 006-university-job-watcher

## 目的

大学の公式採用ページを毎日巡回し、更新を検知してメールで通知するGASを作る。
大学職員の求人は転職サイトに出ないまま公式ページのみで告知されることがあり、
マイナビ等の巡回だけでは母数が不足するため。

## シート構成

- 監視先：A 大学名 / B 採用ページURL / C メモ / D 有効 / E 最終確認日時 / F 前回の状態
- 検知結果：A 検知日時 / B 大学名 / C 検知した記述 / D ページURL / E 確認状況
- スナップショット：A 大学名 / B URL / C ハッシュ / D 本文（差分比較用・自動保存）

## 要件

- 監視先シートの「有効」がオンの行だけ巡回する
- ページ本文をテキスト化し、ハッシュで更新の有無を判定する
- 更新時は、前回本文に無かった行のうち求人に関する語を含むものだけ抽出する
- 教員公募（教授・准教授など）の語を含む行は除外する
- 検知結果をシートに追記し、日次ダイジェストをメールで送る
- 取得失敗したページはエラー内容をシートとメールに記録し、巡回を中断しない
- スプレッドシートに「大学求人監視」メニューを追加する
- 日次トリガーの設定・解除をメニューから行える
- 取得先に負荷をかけないよう、ページ取得の間隔を空ける
- コードは gas/university_job_watcher.gs に作成する
- 使い方を docs/university_job_watcher.md に書く

## 完了条件

- GASを貼り付けて初期設定が実行できる
- 手動チェックで監視先を巡回し、結果がメールで届く
- 2回目以降の実行で差分が検知される
- 取得できないページがあっても他のページの巡回が続く
- READMEに説明が追記される
