# ラグビー部ハイライト動画の作り方（AviUtl）

部活動のかっこいいハイライト動画（ハイプ動画）を AviUtl で作るための手順書です。

目指す仕上がりは次の4つです。

1. 音ハメの高速カット（曲のビートにカット点を合わせる）
2. スローモーション
3. シネマティックな色味
4. テロップ・文字演出

このうち**一番効くのは1の音ハメ**です。素材が普通でも、カットが音に合っているだけでそれらしくなります。逆に、音に合っていないと何をしてもまとまりません。

---

## 0. 全体の流れ

| 手順 | 内容 | かかる時間の目安 |
| --- | --- | --- |
| 1 | 曲を決める | 30分 |
| 2 | 撮影する | 練習1〜2回分 |
| 3 | 素材を選ぶ | 1〜2時間 |
| 4 | AviUtl で組む | 3〜6時間 |
| 5 | 書き出す・公開する | 1時間 |

**曲を先に決めてください。** 曲が決まらないとカットの長さが決まらず、撮影で何を狙うかも決まりません。

---

## 1. 撮影（ここで9割決まります）

編集で盛れる量は素材で決まります。撮り直しはききません。

### カメラ設定

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| フレームレート | **60fps**（スロー用のカットは120fps） | 30fps で撮るとスローにできません |
| シャッタースピード | fps の約2倍（60fps なら 1/120） | 遅すぎるとブレ、速すぎるとパラパラして安っぽくなります |
| 解像度 | 1920×1080 で十分（4K なら寄りの余地が増える） | 1080p60 のほうが編集が軽く済みます |
| 手ブレ補正 | オン | 走りながら撮るなら必須です |
| 時間帯 | **夕方の斜光か曇り** | 昼の順光が一番かっこよく撮れません |

スマホでも撮れます。iPhone なら「ビデオ」→ 60fps、スローが要るところは「スロー」モード（120/240fps）で撮ってください。

### 撮るべきカット

**同じプレーを違うアングルで2回以上**撮るのが基本です。編集はアングルの切り替えで成立します。

**プレー（動きのあるもの）**

- タックルの瞬間（ロー＝芝すれすれの高さから）
- スクラムが組み合う瞬間（真横から寄り）
- パスが手から離れる瞬間
- ラインブレイク・独走（横に並走しながら）
- トライを置く瞬間（ゴール裏から）
- キック（足元の寄り→ボールを目で追う）

**間を作るカット（無音で使う。これが足りないと単調になります）**

- スパイクの紐を結ぶ手
- 円陣、肩を組む背中
- 息が上がっている表情、汗
- ボールを握る手のアップ
- 水をかぶる、タオルで顔を拭く
- 誰もいないグラウンド、ゴールポスト（冒頭と最後に使う）

**枚数の目安**：完成2分の動画に対して、素材は**30〜60カット**あると足ります。

### やりがちな失敗

- **ズームしながら撮る** … デジタルズームは画質が落ち、編集で使いにくくなります。自分が動いてください。
- **1カットを長く撮りすぎる** … 5〜8秒で切って、別アングルで撮り直すほうが使えます。
- **全部を引きで撮る** … 寄りがないと迫力が出ません。
- **縦向きで撮る** … YouTube 用なら必ず横向きです。

## 2. AviUtl の準備

### 必要なもの

この手順書は**従来版の AviUtl（1.10）＋ 拡張編集（0.92）**を前提にしています。

| ソフト | 用途 |
| --- | --- |
| AviUtl 本体（`aviutl.exe`） | 編集ソフト本体 |
| 拡張編集プラグイン（`exedit.auf`） | タイムライン編集。これがないと始まりません |
| L-SMASH Works（`lwinput.aui`） | スマホやカメラの MP4/HEVC を読み込むための入力プラグイン |
| x264guiEx | MP4 で書き出すための出力プラグイン |

いずれも作者の配布ページから入手し、AviUtl のフォルダに入れます。導入手順はバージョンで変わるので、各配布ページの説明に従ってください。

> 新しい **AviUtl2（ExEdit2）** は、フォルダ構成もスクリプトの文字コードも従来版と異なります。この手順書は従来版向けです。

### スクリプトの設置

このリポジトリの `aviutl/` にある3つのファイルを使います。

1. `exedit.auf` が置いてあるフォルダを開きます。
2. その中に `script` という名前のフォルダを作ります（すでにあればそのまま使います）。
3. 次の3ファイルを `script` フォルダにコピーします。
   - `beat_punch.anm`（ビートパンチ）
   - `impact_shake.anm`（衝撃シェイク）
   - `telop_kick.anm`（テロップキック）
4. AviUtl を起動し直します。
5. オブジェクトの設定ダイアログ右上の「＋」→「アニメーション効果」を追加し、種類の一覧に **ビートパンチ／衝撃シェイク／テロップキック**が出れば成功です。

> **注意**：この3つのファイルは **Shift-JIS** で保存してあります。メモ帳などで開いて編集した場合、UTF-8 で保存し直すと項目名が文字化けします。編集するときは文字コードを Shift-JIS のままにしてください。

### プロジェクト設定

新規プロジェクト作成時に次の値にします。

- 画像サイズ：**1920 × 1080**
- フレームレート：**60**
- 音声レート：48000（または 44100）

Instagram のリールに出すなら 1080 × 1920 / 60fps で別に作ります。1本の動画を両方に使い回すのは、寄りの構図が壊れるのでおすすめしません。

## 3. 構成を決める

だいたいこの型に収まります。長さは**1分30秒〜2分30秒**が飽きられません。

| 区間 | 長さ | 内容 |
| --- | --- | --- |
| ① 導入 | 5〜10秒 | 環境音だけ。スパイク、円陣、誰もいないグラウンド。全部スロー |
| ② 開始の一撃 | 1秒 | 曲の1拍目でタイトル、または最初の強い当たり |
| ③ 高速カット | 30〜40秒 | 音ハメ。1カット 0.3〜0.6秒 |
| ④ ブレイク | 3〜5秒 | 音を落として1カットだけスロー。落差が効きます |
| ⑤ サビ | 30〜40秒 | 一番いいプレー。トライ、タックル、突破 |
| ⑥ 締め | 10秒 | 全員の画 → チーム名・年度 |

**先に BGM をタイムラインに置いて、曲の展開（イントロ／Aメロ／サビ）の位置をメモしてから**映像を並べてください。映像から並べると必ず破綻します。

## 4. 音ハメ（最重要）

### 手順

1. `aviutl/beatgrid.html` をブラウザで開きます（ダブルクリックで開きます。通信はしません）。
2. 曲の BPM を入れます。分からなければ、曲を再生しながら「テンポをタップ」を拍に合わせて10回以上叩くと出ます。
3. フレームレートに **60 fps**、「1拍目の位置」に曲の最初のドンの秒数を入れます。
4. 「何拍ごとにカットするか」を選びます。
   - 高速パートは **1拍**（120BPM / 60fps なら 30フレームごと）
   - もっと速くしたいところは **0.5拍**
   - 落ち着かせたいところは **2拍** か **4拍**
5. 表に出たフレーム番号のところで映像を分割します（AviUtl では対象オブジェクトを選んで、そのフレームで右クリック →「分割」、またはショートカットの `S`）。

### コツ

- **音の切れ目でカットを切り替える**、ではなく**ドンと鳴る瞬間に新しいカットが始まる**ようにします。1〜2フレームでも遅れると気持ち悪くなります。
- 全部同じ長さで割ると単調になります。**4カット速い → 1カット長い**のように、たまに息を入れてください。
- カットが足りないときは、同じプレーの寄りと引きを交互に使えば持ちます。

### ビートパンチを使う

カットを割らない場所（長回しのスローなど）でもリズムを保ちたいときに使います。

1. 映像オブジェクトを選び、設定ダイアログ右上の「＋」→「アニメーション効果」→ **ビートパンチ**
2. `BPM` に曲のテンポを入れます
3. `強さ` は 15〜25 から。派手にしたければ 40 以上
4. 音とズレて見えるときは `ズレms` を ±50 くらいずつ動かして合わせます

### 衝撃シェイク

タックルやトライの当たった瞬間のカットに使います。

1. 当たる瞬間で映像を分割し、後ろ側のオブジェクトに **衝撃シェイク**を追加します（オブジェクトの先頭から揺れ始めます）
2. `強さ` 30〜60、`減衰` 8前後
3. **揺らすと画面の端に黒い余白が出ます。** 先にそのオブジェクトの拡大率を 105% にしておいてください

## 5. スローモーション

### 撮影 fps とプロジェクト fps の関係

ここを間違えるとカクカクします。

| 撮影 | プロジェクト | 再生速度 | 結果 |
| --- | --- | --- | --- |
| 120fps | 60fps | 50% | **なめらか（おすすめ）** |
| 240fps | 60fps | 25% | **なめらか（かなり遅くできる）** |
| 60fps | 60fps | 50% | 同じコマが2回出るので少しカクつく |
| 30fps | 60fps | 50% | ガタガタ。実用外 |

**スローにしたいカットは撮影時から 120fps 以上で撮ってください。** これだけは後からどうにもなりません。

### 操作

1. 映像オブジェクトの設定ダイアログにある **再生速度** を `50.00` にします（120fps 素材の場合）。
2. オブジェクトの長さが足りなくなるので、右端をドラッグして伸ばします。
3. 途中から急にスローにしたい（速度ランプ）場合は、その位置で分割し、後ろ側だけ再生速度を下げます。

### 使いどころ

- 導入部（①）は**全部スロー**にすると、後の高速パートとの落差が出ます。
- ブレイク（④）で1カットだけスローにすると、そこが一番印象に残ります。
- 高速カット中に**1カットだけ**スローを混ぜるのも効きます。やりすぎると間延びします。

## 6. シネマティックな色味

### 全体に同じ色を乗せる方法

カットごとに色を調整すると、必ずバラバラになります。**一番上のレイヤーに色味用のフィルタを1本通しで置いてください。** 拡張編集では、フィルタ効果のオブジェクトは**それより下のレイヤーすべて**に掛かります。

1. タイムラインの一番上の空きレイヤーで右クリック →「メディアオブジェクトの追加」→「フィルタ効果の追加」
2. 動画全体の長さまで右端を伸ばします
3. 下記のフィルタを積んでいきます（設定ダイアログ右上の「＋」から追加できます）

### 積む順番と目安の値

| 順 | フィルタ効果 | 狙い | 目安 |
| --- | --- | --- | --- |
| 1 | 色調補正 | コントラストを上げ、彩度を少し下げる | コントラスト +10〜20 / 彩度 −5〜15 |
| 2 | グロー | ハイライトを柔らかく光らせる（映画っぽさの正体） | 強さ 20〜40 / しきい値 高め |
| 3 | シャープ | 少しだけ輪郭を出す | 10〜20 |
| 4 | ノイズ | フィルムらしいざらつき | ごく薄く。10以下 |
| 5 | 色ずれ | 端の色を微妙にずらす | **1〜3。かけすぎると一気に安っぽくなります** |

値はプレビューを見ながら合わせてください。**迷ったら弱くしてください。** シネマティックに見えないときは、たいてい「かけすぎ」が原因です。

### 黒帯（シネスコ）

上下に黒帯を入れると映画の比率になります。

1. 一番上のレイヤーに「図形」を追加し、種類を**四角形**、色を**黒**にします
2. サイズを画面幅より大きくし、Y座標を動かして上端に寄せます
3. 同じものをコピーして下端にも置きます
4. 1920×1080 で 2.35:1（シネスコ）にするなら、帯の高さは**上下それぞれ約 130px** です

**注意**：帯で顔や足元が切れないよう、撮影時から上下に余裕を持って撮ってください。

### 色味づくりの原則

- **暗いところを完全な黒にしない。** 少しだけ持ち上げると、フィルムっぽい落ち着いた画になります。
- 肌の色だけは不自然にしない。ここが崩れると全部おかしく見えます。
- 全カットを同じ時間帯に撮ると、色合わせが劇的に楽になります。

## 7. テロップ・文字演出

### フォント

太いゴシックを使ってください。細い明朝はスポーツ動画に合いません。

- 標準環境なら **メイリオ の太字**
- 無料でよければ **Noto Sans JP（源ノ角ゴシック）の Black**
- 数字・アルファベット（選手名、スコア、年号）は**縦長のサンセリフ**にすると一気にそれらしくなります

### 作り方

1. タイムラインで右クリック →「メディアオブジェクトの追加」→「テキスト」
2. サイズ 60〜120、色は白
3. 「＋」→「縁取り」で黒フチを 2〜4px（背景が明るくても読めるようにする）
4. 「＋」→「影」を薄く
5. 「＋」→「アニメーション効果」→ **テロップキック**

### テロップキックの設定

| 項目 | 目安 | 効果 |
| --- | --- | --- |
| 入り時間 | 0.25〜0.4 | 短いほど鋭い |
| 移動量 | 60〜120（マイナスで上から） | 動く距離 |
| 跳ね | 60〜100 | 行き過ぎてから戻る量。バネ感 |
| 出時間 | 0.2〜0.3 | 最後のフェードアウト |
| 横から入れる | オフ（上下） | オンにすると左右方向 |

**テロップも音に合わせて出してください。** ビートグリッドで出したフレーム番号にテロップの開始位置を置きます。

### 入れる文字の目安

- 冒頭：チーム名、年度（例：`○○高校ラグビー部 2026`）
- 高速パート：短い煽り文句を2〜4回だけ（`NEVER BACK DOWN` など、1〜3語）
- 選手紹介を入れるなら、背番号と名前をセットで
- 最後：チーム名、大会名、日付

**文字を入れすぎないでください。** 画面が説明的になるほど、かっこよさは落ちます。

## 8. 書き出し

1. メニューの「ファイル」→「プラグイン出力」→「拡張 x264 出力(GUI) Ex」
2. 保存先とファイル名を決めます
3. 「ビデオ圧縮」で設定します

| 項目 | 設定 |
| --- | --- |
| 映像 | 1920×1080 / 60fps |
| ビットレート | 12,000〜20,000 kbps |
| 音声 | AAC 192 kbps |

書き出しには実時間の数倍かかります。2分の動画で10〜30分程度みておいてください。

書き出したら、**必ずスマホでも見てください。** PC の大画面では気づかない、文字の小ささや音の小ささが分かります。

## 9. 公開前の確認（ここは必ず読んでください）

学校の部活動の動画なので、作品の出来より先に片づけることが2つあります。

### BGM の著作権

**市販曲をそのまま使って YouTube などに公開すると、ブロックされるか、広告収入が権利者に行きます。** 学校の公式アカウントで出すなら、著作権上問題のない音源を使ってください。

- YouTube オーディオライブラリ（YouTube で使う分には無料）
- DOVA-SYNDROME、甘茶の音楽工房（フリー BGM）
- Artlist、Epidemic Sound（有料。使用条件は各サービスの規約を確認）

いずれも「どこで公開するか」で条件が変わります。**利用規約を読んでから使ってください。** 校内での上映のみと、インターネット公開は、扱いが違います。

### 生徒の肖像権

顔が特定できる映像をインターネットで公開するには、**本人と保護者の同意**が必要です。

- 学校で使っている「写真・動画の公開に関する同意書」の範囲を確認してください
- 同意がない生徒が映っている場合は、そのカットを使わないのが確実です
- 心配な場合は、YouTube の**限定公開（リンクを知っている人だけ）**にして、部内・保護者に URL を配る方法があります
- 制服の名札、ゼッケンの氏名、ジャージのフルネームが読める寄りのカットは注意してください

**公開する前に、必ず管理職・顧問の確認を通してください。**

## 10. うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| スクリプトが一覧に出ない | `script` フォルダの場所が違います。`exedit.auf` と同じ階層か確認してください |
| 項目名が「?????」になる | ファイルが UTF-8 で保存されています。Shift-JIS で保存し直してください |
| 動画ファイルが読み込めない | L-SMASH Works が入っていません。HEVC(H.265) のスマホ動画で特に起きます |
| プレビューが重い | プレビューの解像度を 1/2 に下げてください。書き出しの画質には影響しません |
| スローがカクカクする | 素材が 60fps 以下です。120fps で撮り直すしかありません |
| 音とカットが少しズレる | ビートパンチの `ズレms`、またはカット位置を1〜2フレーム単位で動かします |
| なんとなく安っぽい | たいてい「エフェクトのかけすぎ」です。色ずれとノイズを半分にしてみてください |
| 途中で飽きる | 長すぎます。2分を超えていたら削ってください |
