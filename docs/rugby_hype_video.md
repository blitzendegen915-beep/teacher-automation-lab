# ラグビー部ハイライト動画の作り方（AviUtl）

部活動のかっこいいハイライト動画（ハイプ動画）を AviUtl で作るための手順書です。

目指す仕上がりは次の4つです。

1. 音ハメの高速カット（曲のビートにカット点を合わせる）
2. スローモーション
3. シネマティックな色味
4. テロップ・文字演出

---

## 参考動画の実測結果

参考として渡された動画（スマブラの大会「篝火14」のトレーラー、37秒＋42秒）を、
コマ単位・音声単位で解析した結果です。**推測ではなく実測値**なので、ここに合わせれば近づきます。

| 項目 | 実測値 | 意味 |
| --- | --- | --- |
| 画面比 | 2.155:1（黒帯なし） | 素材自体が横長。1920×1080で再現するなら上下に**約95pxずつ**黒帯 |
| カット数 | 37秒で42カット / 42秒で51カット | 平均 0.85秒に1回 |
| カットの長さ | 中央値 **0.6秒**、25%点 0.25〜0.32秒、最長 2.7〜3.3秒 | 均等ではなく緩急がある |
| 短いカットの割合 | 0.2秒未満が2割 | 見せ場で数カット連射している |
| BPM | 99.4（1拍0.604秒） | 2本とも同じ曲 |
| 音ハメ | **していない**（ビート整合が偶然の範囲） | カットは動きの見せ場で切っている |
| 黒レベル | 16〜18 / 255 | 黒を潰さず持ち上げている＝フィルム調 |
| 白レベル | 約209 / 255 | 白飛びさせていない |
| 平均の明るさ | 85〜87 / 255 | 全体にかなり暗い |
| 彩度 | 41〜43% | 意外と鮮やか。地味にしすぎていない |
| 色かぶり | R−B = +9〜+12 | 暖色寄り（炎・熱） |

### ここから分かる、大事なこと3つ

**1. 厳密な音ハメはしていません。**
カットがビートに乗っている割合を測ったところ、偶然の範囲でした。
つまりこの動画は、拍で機械的に割るのではなく、**当たる瞬間・走り出す瞬間で切っています**。
曲とは「展開（イントロ・サビ・ブレイク）」の単位で合わせているだけです。
音ハメは有効な技ですが、この参考動画を目指すなら必須ではありません。

**2. カットは思ったより速くありません。**
中央値0.6秒です。ずっと0.3秒で切り続けているわけではなく、
**基準の速さ → 0.2秒未満を3〜5連発 → 1.5〜3秒の長回しで呼吸**、という緩急でできています。
均等に速くすると、速いのに単調になります。

**3. 暗くて、黒が浮いていて、暖色です。**
平均輝度86/255はかなり暗い部類です。暗いからこそ白い文字が映えます。
黒を0まで落とさず17前後に浮かせるのがフィルムらしさの正体です。

## 0. 全体の流れ

| 手順 | 内容 | かかる時間の目安 |
| --- | --- | --- |
| 1 | 曲を決める | 30分 |
| 2 | 撮影する | 練習1〜2回分 |
| 3 | 素材を選ぶ | 1〜2時間 |
| 4 | AviUtl で組む | 3〜6時間 |
| 5 | 書き出す・公開する | 1時間 |

**曲を先に決めてください。** 曲が決まらないとカットの長さが決まらず、撮影で何を狙うかも決まりません。

## 1. 撮影（ここで9割決まります）

編集で盛れる量は素材で決まります。撮り直しはききません。

### カメラ設定

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| フレームレート | **60fps**（スロー用のカットは120fps） | 30fps で撮るとスローにできません |
| シャッタースピード | fps の約2倍（60fps なら 1/120） | 遅すぎるとブレ、速すぎるとパラパラして安っぽくなります |
| 解像度 | 1920×1080 で十分（4K なら寄りの余地が増える） | 1080p60 のほうが編集が軽く済みます |
| 手ブレ補正 | オン | 走りながら撮るなら必須です |
| 時間帯 | **夕方の斜光か曇り** | 昼の順光が一番かっこよく撮れません |

スマホでも撮れます。iPhone なら「ビデオ」→ 60fps、スローが要るところは「スロー」モード（120/240fps）で撮ってください。

### 撮るべきカット

**同じプレーを違うアングルで2回以上**撮るのが基本です。編集はアングルの切り替えで成立します。

**プレー（動きのあるもの）**

- タックルの瞬間（ロー＝芝すれすれの高さから）
- スクラムが組み合う瞬間（真横から寄り）
- パスが手から離れる瞬間
- ラインブレイク・独走（横に並走しながら）
- トライを置く瞬間（ゴール裏から）
- キック（足元の寄り→ボールを目で追う）

**間を作るカット（無音で使う。これが足りないと単調になります）**

- スパイクの紐を結ぶ手
- 円陣、肩を組む背中
- 息が上がっている表情、汗
- ボールを握る手のアップ
- 水をかぶる、タオルで顔を拭く
- 誰もいないグラウンド、ゴールポスト（冒頭と最後に使う）

**枚数の目安**：完成2分の動画に対して、素材は**30〜60カット**あると足ります。

### やりがちな失敗

- **ズームしながら撮る** … デジタルズームは画質が落ち、編集で使いにくくなります。自分が動いてください。
- **1カットを長く撮りすぎる** … 5〜8秒で切って、別アングルで撮り直すほうが使えます。
- **全部を引きで撮る** … 寄りがないと迫力が出ません。
- **縦向きで撮る** … YouTube 用なら必ず横向きです。

## 2. AviUtl の準備

### 必要なもの

この手順書は**従来版の AviUtl（1.10）＋ 拡張編集（0.92）**を前提にしています。

| ソフト | 用途 |
| --- | --- |
| AviUtl 本体（`aviutl.exe`） | 編集ソフト本体 |
| 拡張編集プラグイン（`exedit.auf`） | タイムライン編集。これがないと始まりません |
| L-SMASH Works（`lwinput.aui`） | スマホやカメラの MP4/HEVC を読み込むための入力プラグイン |
| x264guiEx | MP4 で書き出すための出力プラグイン |

いずれも作者の配布ページから入手し、AviUtl のフォルダに入れます。導入手順はバージョンで変わるので、各配布ページの説明に従ってください。

> 新しい **AviUtl2（ExEdit2）** は、フォルダ構成もスクリプトの文字コードも従来版と異なります。この手順書は従来版向けです。

### スクリプトの設置

このリポジトリの `aviutl/` にある5つのファイルを使います。

1. `exedit.auf` が置いてあるフォルダを開きます。
2. その中に `script` という名前のフォルダを作ります（すでにあればそのまま使います）。
3. 次の5ファイルを `script` フォルダにコピーします。
   - `beat_punch.anm`（ビートパンチ）
   - `impact_shake.anm`（衝撃シェイク）
   - `telop_kick.anm`（テロップキック）
   - `telop_drift.anm`（テロップドリフト）
   - `ease_push.anm`（イーズ寄り）
4. AviUtl を起動し直します。
5. オブジェクトの設定ダイアログ右上の「＋」→「アニメーション効果」を追加し、種類の一覧に **ビートパンチ／衝撃シェイク／テロップキック／テロップドリフト／イーズ寄り**が出れば成功です。

> **注意**：この5つのファイルは **Shift-JIS** で保存してあります。メモ帳などで開いて編集した場合、UTF-8 で保存し直すと項目名が文字化けします。編集するときは文字コードを Shift-JIS のままにしてください。

### プロジェクト設定

新規プロジェクト作成時に次の値にします。

- 画像サイズ：**1920 × 1080**
- フレームレート：**60**
- 音声レート：48000（または 44100）

Instagram のリールに出すなら 1080 × 1920 / 60fps で別に作ります。1本の動画を両方に使い回すのは、寄りの構図が壊れるのでおすすめしません。

## 3. 構成を決める

### この動画の構成（決定版）

**歩き → 準備 → プレー → 衝突**の順で登っていく構成です。合計 **1分5秒〜1分25秒**。

| 区間 | 尺 | 内容 | スロー | 動きとイージング |
| --- | --- | --- | --- | --- |
| ⓪ 冷たい開幕（任意） | 0.5秒 | スクラムの衝突を一瞬だけ → 黒 | なし | 動かさない。一撃で切る |
| ① 歩き | 6〜8秒 | 足元・背中・手・肩。**引きで撮らない**。環境音のみ | **50%〜25%** | イーズ寄り／拡大6〜10・カーブ **+60** |
| ② 準備 | 15〜20秒 | 会議、テーピング、装具、円陣、聞いている顔。ここで曲が入る | 一部だけ50% | イーズ寄り／拡大5・カーブ **+40**（控えめに） |
| ③ プレー | 30〜40秒 | パス、キック、走り。表情を1〜2カット挟む | 蹴る瞬間・パスが離れる瞬間だけ25〜50% | **動かさない**。カットの速さで見せる |
| ④ ブレイク | 3秒 | **無音**。顔の寄り1カットだけ | 25% | イーズ寄り／カーブ **−60**（じわっと動き出す） |
| ⑤ スクラム | 5〜8秒 | 組む → セット → 衝突 | セットまで等速 → **当たった瞬間から25%** | 衝撃シェイク。寄りは付けない |
| ⑥ 締め | 3秒 | 黒 → チーム名・年度 | — | テロップドリフト |

### 各区間の狙いと注意

**① 歩き** — 一番かっこよく見えて、**一番間延びします**。引きで歩く人を10秒撮ると確実に飽きます。
寄りで刻んでください（スパイクが芝を踏む、背中、揺れる手、肩）。逆光か夕方。順光の昼だとただの散歩に見えます。
**6〜8秒で切る。** それ以上は持ちません。

**② 準備** — 素材として一番強い区間です。テーピング、ヘッドキャップ、紐を結ぶ手。
ホワイトボードを指す手、**聞いている顔**も必ず入れてください。ここで曲を入れると流れがはっきりします。

**③ プレー** — 一番速くする区間。蹴る足の寄り → ボールが飛ぶ → 追う目線、の3カット割りが効きます。

**④ ブレイク** — **ここが全体で一番大事です。** 曲を切って、1カットだけスローで表情を見せる。
落差がないと、最後がただ大きい音で終わるだけになります。

**⑤ スクラム** — 絵として難しい区間です。
- **真横から、低く**（芝すれすれ）。正面や上からは形が読めません
- 「クラウチ、バインド、**セット**」の**セットの瞬間**だけが使えます
- **音も同時に終わらせてください。** 衝突で映像を切るなら曲もそこで切る。曲が続くと一気にしぼみます

### 全区間に「顔」を刺す

参考動画を解析して一番はっきり出たのが、**競技の映像と人の映像を絶えず交互に混ぜている**ことでした。
行動だけを並べると記録映像になります。感情が乗るのは顔です。
**各区間に必ず1〜2カット、寄りの表情**を入れてください。息が上がっている顔、汗、目線、キックを見送る横顔。

### 組む順番

**先に BGM をタイムラインに置いて、曲の展開（イントロ／Aメロ／サビ）の位置をメモしてから**映像を並べてください。
映像から並べると必ず破綻します。④のブレイクは、曲の音が落ちるところに合わせると自然です。

## 4. カットの割り方と音ハメ

> **参考動画は音ハメしていません**（実測済み）。まずは下の「カットの緩急」で組んでください。
> 音ハメは、そのうえで使いたければ使う技です。曲がEDM系で拍がはっきりしている場合は効きます。

### カットの緩急（こちらが本命）

参考動画の分布を再現するなら、この繰り返しで組みます。

| 区間 | カットの長さ | 何をする |
| --- | --- | --- |
| 基準 | 0.6秒前後 | プレーを普通に見せる。3〜5カット続ける |
| 連射 | 0.15〜0.2秒 | 見せ場で3〜5カット連発する。寄り・引き・ローを切り替える |
| 呼吸 | 1.5〜3秒 | 1カット長く見せる。スローを混ぜると効く |

**切る位置は、拍ではなく「動きの瞬間」です。** 当たった瞬間、走り出した瞬間、
ボールが手を離れた瞬間。ここで切ると、音に合っていなくても気持ちよくなります。

### 音ハメする場合の手順

1. `aviutl/beatgrid.html` をブラウザで開きます（ダブルクリックで開きます。通信はしません）。
2. 曲の BPM を入れます。分からなければ、曲を再生しながら「テンポをタップ」を拍に合わせて10回以上叩くと出ます。
3. フレームレートに **60 fps**、「1拍目の位置」に曲の最初のドンの秒数を入れます。
4. 「何拍ごとにカットするか」を選びます。
   - 高速パートは **1拍**（120BPM / 60fps なら 30フレームごと）
   - もっと速くしたいところは **0.5拍**
   - 落ち着かせたいところは **2拍** か **4拍**
5. 表に出たフレーム番号のところで映像を分割します（AviUtl では対象オブジェクトを選んで、そのフレームで右クリック →「分割」、またはショートカットの `S`）。

### コツ

- **音の切れ目でカットを切り替える**、ではなく**ドンと鳴る瞬間に新しいカットが始まる**ようにします。1〜2フレームでも遅れると気持ち悪くなります。
- 全部同じ長さで割ると単調になります。**4カット速い → 1カット長い**のように、たまに息を入れてください。
- カットが足りないときは、同じプレーの寄りと引きを交互に使えば持ちます。

### ビートパンチを使う

カットを割らない場所（長回しのスローなど）でもリズムを保ちたいときに使います。

1. 映像オブジェクトを選び、設定ダイアログ右上の「＋」→「アニメーション効果」→ **ビートパンチ**
2. `BPM` に曲のテンポを入れます
3. `強さ` は 15〜25 から。派手にしたければ 40 以上
4. 音とズレて見えるときは `ズレms` を ±50 くらいずつ動かして合わせます

### 衝撃シェイク

タックルやトライの当たった瞬間のカットに使います。

1. 当たる瞬間で映像を分割し、後ろ側のオブジェクトに **衝撃シェイク**を追加します（オブジェクトの先頭から揺れ始めます）
2. `強さ` 30〜60、`減衰` 8前後
3. **揺らすと画面の端に黒い余白が出ます。** 先にそのオブジェクトの拡大率を 105% にしておいてください

## 5. スローモーションとイージング

### 撮影 fps とプロジェクト fps の関係

ここを間違えるとカクカクします。

| 撮影 | プロジェクト | 再生速度 | 結果 |
| --- | --- | --- | --- |
| 120fps | 60fps | 50% | **なめらか（おすすめ）** |
| 240fps | 60fps | 25% | **なめらか（かなり遅くできる）** |
| 60fps | 60fps | 50% | 同じコマが2回出るので少しカクつく |
| 30fps | 60fps | 50% | ガタガタ。実用外 |

**スローにしたいカットは撮影時から 120fps 以上で撮ってください。** これだけは後からどうにもなりません。

### 操作

1. 映像オブジェクトの設定ダイアログにある **再生速度** を `50.00` にします（120fps 素材の場合）。
2. オブジェクトの長さが足りなくなるので、右端をドラッグして伸ばします。
3. 途中から急にスローにしたい（速度ランプ）場合は、その位置で分割し、後ろ側だけ再生速度を下げます。

### 使いどころ

- 歩き（①）は**全部スロー**にすると、後の高速パートとの落差が出ます。
- ブレイク（④）で1カットだけスローにすると、そこが一番印象に残ります。
- プレー（③）は、**蹴る瞬間・パスが手を離れる瞬間だけ**を落とします。
- スクラム（⑤）は、セットまで等速で、**当たった瞬間から**落とします。

**スローは「落差」でしか効きません。** 全部スローにすると、遅いだけの動画になります。
目安として、全体の3割を超えたら入れすぎです。

### スローにもイージングを掛ける（速度ランプ）

100% から急に 25% へ切り替えると、そこに段差が見えます。**刻んでください。**

| 分割 | 再生速度 |
| --- | --- |
| 1つ目 | 100% |
| 2つ目 | 75% |
| 3つ目 | 50% |
| 4つ目 | 35% |
| 5つ目 | 25% |

各 0.1〜0.2秒ずつに分割して、それぞれの **再生速度** を設定します。
3段でもかなり滑らかになります。5段まで刻めばほぼ気づかれません。

戻すときも同じで、25% → 35% → 50% → 75% → 100% と刻みます。
**スクラムの衝突は戻さず、落としたまま終わらせてください。**

より丁寧にやるなら「時間制御」のフィルタ効果を使って、時間の進み方そのものを
中間点＋加減速移動で曲線にする方法もあります。ただし設定が複雑なので、
まずは上の分割方式で十分です。

### イージング（動きの緩急）

同じ距離を同じ時間で動かしても、**速度の変化のさせ方**で印象がまったく変わります。
ここを意識すると、素人っぽさが一番減ります。

#### 原則

| カーブ | 動き方 | 印象 | 使いどころ |
| --- | --- | --- | --- |
| **イーズアウト**（+側） | 勢いよく出て、長く余韻を残して止まる | 自然・気持ちいい | **基本はこれ**。寄り、テロップ、ほぼ全部 |
| **イーズイン**（−側） | そろそろ出て、最後に加速する | 溜め・これから起きる予感 | ブレイク、クライマックス直前 |
| **等速**（0） | 一定 | 無機質・機械的 | キャッチコピーの流し、長回しの寄り |

**映像では「動き出しは速く、止まりは長く」が自然に見えます。** 現実の物体がそう動くからです。
迷ったらイーズアウト側にしてください。等速の寄りは、それだけで「編集ソフトの初期設定のまま」に見えます。

#### AviUtl での掛け方は2通り

**1. 中間点＋移動方法（本体の機能）**

パラメータの数値を右クリックすると、移動方法を選べます。

| 移動方法 | 動き |
| --- | --- |
| 直線移動 | 等速 |
| 加減速移動 | 両端が緩む（イーズインアウト） |
| 曲線移動 | 中間点どうしを滑らかにつなぐ |
| 瞬間移動 | 中間点で一気に飛ぶ |

複雑な軌跡（何度も向きが変わる動き）はこちらが向いています。

**2. イーズ寄りスクリプト（`ease_push.anm`）**

中間点を打たずに、**カーブ1本のつまみ**で緩急を連続的に変えられます。
単純な寄り・引き・流しはこちらのほうが早く、微調整も効きます。

1. 映像オブジェクトを選び「＋」→「アニメーション効果」→ **イーズ寄り**
2. `拡大量` を 5〜10（寄る量）
3. `カーブ` を +60（基本）／−60（溜め）／0（無機質）
4. 引きの動きにしたいときは `逆にする` をオンに

#### やりすぎの目安

- **全カットに寄りを付けない。** 動かすのは 3〜4カットに1つ。全部動くと落ち着きません
- **拡大は8%程度まで。** 20%を超えると酔います
- **速いカット（0.2秒以下）には動きを付けない。** 見えないうえに、ちらついて汚くなります

## 6. シネマティックな色味

### 全体に同じ色を乗せる方法

カットごとに色を調整すると、必ずバラバラになります。**一番上のレイヤーに色味用のフィルタを1本通しで置いてください。** 拡張編集では、フィルタ効果のオブジェクトは**それより下のレイヤーすべて**に掛かります。

1. タイムラインの一番上の空きレイヤーで右クリック →「メディアオブジェクトの追加」→「フィルタ効果の追加」
2. 動画全体の長さまで右端を伸ばします
3. 下記のフィルタを積んでいきます（設定ダイアログ右上の「＋」から追加できます）

### 積む順番と目安の値

| 順 | フィルタ効果 | 狙い | 目安 |
| --- | --- | --- | --- |
| 1 | 色調補正 | 全体を暗く、わずかに暖色へ | 明るさ −10〜−20 / 彩度は落としすぎない（−5程度まで） |
| 2 | グロー | ハイライトを柔らかく光らせる（映画っぽさの正体） | 強さ 20〜40 / しきい値 高め |
| 3 | シャープ | 少しだけ輪郭を出す | 10〜20 |
| 4 | ノイズ | フィルムらしいざらつき | ごく薄く。10以下 |
| 5 | 色ずれ | 端の色を微妙にずらす | **1〜3。かけすぎると一気に安っぽくなります** |

### 黒を持ち上げる（これが一番効きます）

参考動画の黒レベルは **17／255**。真っ黒（0）ではなく浮いています。これがフィルムらしさの正体です。

やり方は簡単で、**一番上のレイヤーに黒い四角形（図形）を画面いっぱいに置き、不透明度を92〜95%にする**だけです。
暗いところだけが持ち上がり、一気に落ち着いた画になります。

### 数値の目安（参考動画の実測値）

作業中に確認する基準です。

| 項目 | 目標 |
| --- | --- |
| 黒レベル | 15〜20 / 255（潰さない） |
| 白レベル | 205〜215 / 255（白飛びさせない） |
| 平均の明るさ | 85〜90 / 255（暗め） |
| 彩度 | 40%前後（落としすぎない） |
| 色かぶり | 赤が青より少し強い（暖色寄り） |

値はプレビューを見ながら合わせてください。**迷ったら弱くしてください。** シネマティックに見えないときは、たいてい「かけすぎ」が原因です。

### 黒帯（シネスコ）

上下に黒帯を入れると映画の比率になります。

1. 一番上のレイヤーに「図形」を追加し、種類を**四角形**、色を**黒**にします
2. サイズを画面幅より大きくし、Y座標を動かして上端に寄せます
3. 同じものをコピーして下端にも置きます
4. 帯の高さは、参考動画と同じ 2.155:1 にするなら **上下それぞれ約 95px**、
   一般的なシネスコ（2.35:1）にするなら **約 130px** です

参考動画には黒帯そのものは付いていません（素材が最初から 2.155:1 の横長）。
1920×1080 で撮ったものを同じ見た目にするために帯を足す、という位置づけです。

**注意**：帯で顔や足元が切れないよう、撮影時から上下に余裕を持って撮ってください。

### 色味づくりの原則

- **暗いところを完全な黒にしない。** 少しだけ持ち上げると、フィルムっぽい落ち着いた画になります。
- 肌の色だけは不自然にしない。ここが崩れると全部おかしく見えます。
- 全カットを同じ時間帯に撮ると、色合わせが劇的に楽になります。

## 7. テロップ・文字演出

> 参考動画を細かく見た結果、当初書いていた「太字＋黒フチ」は主流ではありませんでした。
> **情報テロップは細めの白文字・フチなし**で、暗い映像に乗せて成立させています。
> 極太を使うのはタイトルとキャッチコピーだけです。

### 一番効く型：キャッチコピーを出しっぱなしにする

参考動画で一番強い演出がこれです。「情熱を焚べろ。」という一文を、
**約3秒そのまま出したまま、下の映像を8〜10カット切り替えて**います。
さらに文字自体はゆっくり下へ流れていきます。

1. テキストオブジェクトを **3秒前後**の長さで置く
2. その下のレイヤーで映像を5〜10カットに割る
3. テキストに「＋」→「アニメーション効果」→ **テロップドリフト**
4. 「縦に流す」を 150 前後、「拡大変化」を 4 くらいに

文字が動かず映像だけが変わるので、言葉に重みが出ます。短いテロップを
パッパッと出すより、はるかに効きます。

### 情報を出す型：小さいラベル＋大きい値

参考動画の情報テロップは、すべてこの2行組でした。

```
場 所                    ← 小さく、字間を広めに
所沢くすのきホール          ← 大きく、細めのウェイト
```

ラグビー部なら、こう置き換えられます。

```
会 場                     DAY1                  部員数
○○高校グラウンド           対 ○○高校             38
```

- 上のラベルは下の文字の **1/3〜1/4のサイズ**、字間を広く
- 下は大きく、**細め**。フチ取りは付けない
- 左揃えで、画面の下1/3あたり

**数字を1つ出すだけで説得力が変わります。** 部員数、連勝記録、スコア、創部年数など。

### フォント

| 用途 | ウェイト |
| --- | --- |
| タイトル・締めのロゴ | 極太（ここだけ太くする） |
| キャッチコピー | 太〜極太、フチなし・影は薄く |
| 情報（会場・日付・スコア） | 細〜中、フチなし |

- 標準環境なら **メイリオ**、無料なら **Noto Sans JP（源ノ角ゴシック）**
- 数字・アルファベットは**縦長のサンセリフ**にすると引き締まります
- 白は純白より、**わずかに暖色寄りの白**のほうが映像になじみます

### 短く出すテロップの作り方

1. タイムラインで右クリック →「メディアオブジェクトの追加」→「テキスト」
2. サイズ 60〜120、色は白
3. 背景が明るい場合だけ「＋」→「縁取り」で黒フチを 2〜4px（暗い映像なら不要）
4. 「＋」→「影」を薄く
5. 「＋」→「アニメーション効果」→ **テロップキック**

### テロップキックの設定

| 項目 | 目安 | 効果 |
| --- | --- | --- |
| 入り時間 | 0.25〜0.4 | 短いほど鋭い |
| 移動量 | 60〜120（マイナスで上から） | 動く距離 |
| 跳ね | 60〜100 | 行き過ぎてから戻る量。バネ感 |
| 出時間 | 0.2〜0.3 | 最後のフェードアウト |
| 横から入れる | オフ（上下） | オンにすると左右方向 |

**テロップも音に合わせて出してください。** ビートグリッドで出したフレーム番号にテロップの開始位置を置きます。

### 入れる文字の目安

- 冒頭：チーム名、年度（例：`○○高校ラグビー部 2026`）
- 高速パート：短い煽り文句を2〜4回だけ（`NEVER BACK DOWN` など、1〜3語）
- 選手紹介を入れるなら、背番号と名前をセットで
- 最後：チーム名、大会名、日付

**文字を入れすぎないでください。** 画面が説明的になるほど、かっこよさは落ちます。

## 8. 書き出し

1. メニューの「ファイル」→「プラグイン出力」→「拡張 x264 出力(GUI) Ex」
2. 保存先とファイル名を決めます
3. 「ビデオ圧縮」で設定します

| 項目 | 設定 |
| --- | --- |
| 映像 | 1920×1080 / 60fps |
| ビットレート | 12,000〜20,000 kbps |
| 音声 | AAC 192 kbps |

書き出しには実時間の数倍かかります。2分の動画で10〜30分程度みておいてください。

書き出したら、**必ずスマホでも見てください。** PC の大画面では気づかない、文字の小ささや音の小ささが分かります。

## 9. 公開前の確認（ここは必ず読んでください）

学校の部活動の動画なので、作品の出来より先に片づけることが2つあります。

### BGM の著作権

**市販曲をそのまま使って YouTube などに公開すると、ブロックされるか、広告収入が権利者に行きます。** 学校の公式アカウントで出すなら、著作権上問題のない音源を使ってください。

- YouTube オーディオライブラリ（YouTube で使う分には無料）
- DOVA-SYNDROME、甘茶の音楽工房（フリー BGM）
- Artlist、Epidemic Sound（有料。使用条件は各サービスの規約を確認）

いずれも「どこで公開するか」で条件が変わります。**利用規約を読んでから使ってください。** 校内での上映のみと、インターネット公開は、扱いが違います。

### 生徒の肖像権

顔が特定できる映像をインターネットで公開するには、**本人と保護者の同意**が必要です。

- 学校で使っている「写真・動画の公開に関する同意書」の範囲を確認してください
- 同意がない生徒が映っている場合は、そのカットを使わないのが確実です
- 心配な場合は、YouTube の**限定公開（リンクを知っている人だけ）**にして、部内・保護者に URL を配る方法があります
- 制服の名札、ゼッケンの氏名、ジャージのフルネームが読める寄りのカットは注意してください

**公開する前に、必ず管理職・顧問の確認を通してください。**

## 10. うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| スクリプトが一覧に出ない | `script` フォルダの場所が違います。`exedit.auf` と同じ階層か確認してください |
| 項目名が「?????」になる | ファイルが UTF-8 で保存されています。Shift-JIS で保存し直してください |
| 動画ファイルが読み込めない | L-SMASH Works が入っていません。HEVC(H.265) のスマホ動画で特に起きます |
| プレビューが重い | プレビューの解像度を 1/2 に下げてください。書き出しの画質には影響しません |
| スローがカクカクする | 素材が 60fps 以下です。120fps で撮り直すしかありません |
| 音とカットが少しズレる | ビートパンチの `ズレms`、またはカット位置を1〜2フレーム単位で動かします |
| なんとなく安っぽい | たいてい「エフェクトのかけすぎ」です。色ずれとノイズを半分にしてみてください |
| 途中で飽きる | 長すぎます。2分を超えていたら削ってください |
