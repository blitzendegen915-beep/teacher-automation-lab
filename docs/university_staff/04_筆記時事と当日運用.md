# 04 筆記試験・高等教育キーワード・当日運用

---

## 1. 高等教育キーワード（面接・小論文で「知っている側」に立つための最小セット）

面接で全部使う必要はない。**1〜2語を正確に使えば十分**、多用すると借り物に見える。

### 制度・質保証

| 用語 | 押さえるべき中身 |
| --- | --- |
| 3つのポリシー | DP(卒業認定・学位授与)／CP(教育課程編成・実施)／AP(入学者受入れ)。この3つが一貫していることが求められる |
| 内部質保証 | 大学が自ら点検・評価し、改善につなげる仕組み。認証評価でも中核的な観点 |
| 認証評価 | 国の認証を受けた機関による定期的な第三者評価。7年以内ごとが基本 |
| 設置基準 | 大学設置の最低要件。近年は教育課程や教員組織の規定が柔軟化 |
| 単位の実質化 | 授業時間外学修を含めて単位に見合う学修時間を確保すること |
| SD（スタッフ・ディベロップメント） | 職員の資質向上のための研修等。**義務化されている**＝職員が運営の担い手という位置づけ |
| FD（ファカルティ・ディベロップメント） | 教員の教育力向上のための組織的取組 |
| 学修者本位の教育 | 教える側ではなく学ぶ側を起点に教育を設計する考え方 |
| ガバナンス改革 | 理事会・学長のリーダーシップと意思決定の明確化 |

### 経営・募集

| 用語 | 押さえるべき中身 |
| --- | --- |
| 18歳人口減少 | 構造的な志願者減。定員充足だけを追うとミスマッチと中退を招く |
| 定員充足率 | 私学助成にも関わる指標。未充足も超過も問題になる |
| 私学助成（経常費補助） | 私立大学の主要な収入の一つ。教育の質に関する指標と連動する仕組みがある |
| 総合型選抜／学校推薦型選抜 | 年内入試の比重が上昇。学力の担保と評価方法の設計が課題 |
| 高大接続 | 高校と大学の学びの接続。入試だけでなく教育内容の連続性が論点 |
| リカレント教育／リスキリング | 社会人の学び直し。18歳以外への大学の開放 |
| 留学生受入れ | 在留資格管理・日本語教育・卒業後の進路支援まで含む |

### 学生支援

| 用語 | 押さえるべき中身 |
| --- | --- |
| 合理的配慮 | 障害のある学生への必要な配慮。**法的義務**（私立大学も対象） |
| 修学支援新制度 | 授業料減免・給付型奨学金。要件確認と手続きが職員業務 |
| 中退予防／早期発見 | 出席・成績データの活用と部署間連携が鍵 |
| キャリア教育 | 就職支援だけでなく、正課との接続が求められる |

> **附属校勤務からの応用**：附属校での勤務経験があるため、「高大接続」「内部進学」「系列校連携」は自分の実体験として語れる。
> ここは他の応募者が体験ベースで語れない領域なので、面接で意識的に持ち込む。

## 2. 時事の押さえ方（当日までに30分でやる）

- 志望大学の**公式サイトのニュース欄を直近3か月分**ざっと見る（新設・協定・受賞・イベント）
- 志望大学の**中期計画／将来構想**のPDFを1本だけ読む（柱の名前を1つ覚える）
- 文部科学省の高等教育関連の最近の話題を1つ（中央教育審議会の答申・大学設置基準・修学支援など）
- 一般ニュースを1つ用意（教育以外でも可。「関心を持っている」と言える程度に）

※ 情報は**必ず一次情報（大学公式・文科省）で確認**する。うろ覚えの数字は面接で言わない。

## 3. 適性検査・筆記（マイナビ系の中途で出る形式）

| 形式 | 対策 |
| --- | --- |
| SPI（言語・非言語） | 非言語が鬼門。**推論・確率・割合・速度算**を市販問題集で1冊。教員だと言語は落とさない |
| 玉手箱・TG-WEB | 出題形式が独特。Webテスト指定があれば形式名を先に確認 |
| 一般常識・時事 | 上記キーワード＋新聞レベルの時事 |
| 適性検査（性格） | 一貫性が命。**正直に、ただしブレずに**答える。矛盾を検出する設問がある |
| 英語 | 英検1級保持者としては落とせない。ここは得点源 |
| PCスキル | Excel/Word の実技が課される大学もある。VLOOKUP・IF・ピボットは触っておく |

**優先順位**：時間がないなら、SPI非言語 →小論文 →面接エピソードの順ではなく、
**面接エピソード → 小論文 → SPI非言語**。面接で落ちる比率が最も高い。

## 4. 応募書類チェックリスト

- [ ] 履歴書（写真は3か月以内、スーツ、背景無地）
- [ ] 職務経歴書（**大学職員向けに書き直す**。教科指導の記述を減らし、運営・調整・改善の記述を増やす）
- [ ] 志望動機書／エントリーシート（固有名詞2つ以上）
- [ ] 卒業・修了証明書、成績証明書（**発行に日数がかかる。最優先で手配**）
- [ ] 資格証明（英検1級の合格証明書。再発行が必要なら早めに）
- [ ] 教員免許状の写し（求められる場合）
- [ ] 送付状（郵送の場合）
- [ ] 提出方法・締切・必着か消印有効かの確認

> **職務経歴書の書き分け**：私学教員向けと大学職員向けは**別ファイルで管理する**。
> 使い回すと「教員に戻りたい人」に見える。

## 6. 心構え（追い詰められている時に読む用）

- 教員の転職市場と大学職員の中途市場は**別物**。私学教員で最終まで行っている実績は、大学職員選考の合否とは無関係だ。落ち続けているという感覚を持ち込まない。
- 大学職員の中途採用は**倍率が高い**。落ちても実力の否定ではなく、席の数の問題であることが多い。1本に賭けない設計にする。
- 同時進行している私学教員の応募を止める必要はない。**片方が決まるまで、両方走らせるのが正しい**。
- 準備の質は、今日この時点でほぼ決まった。あとは**当日に平常心で出せるか**だけ。新しい対策を増やすより、作ったものを3回音読するほうが効く。
