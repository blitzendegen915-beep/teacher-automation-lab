# 大学職員 採用試験対策パック

高校英語科教員（私立中高一貫・約7年）の経歴を前提に、大学職員の中途採用選考（マイナビ経由）を突破するための対策一式。
**公開リポジトリのため、氏名・現勤務先・応募先などの固有情報は記載しない。** 実際の応募書類は手元で管理する。

## 構成

| ファイル | 内容 | 使うタイミング |
| --- | --- | --- |
| `00_経歴棚卸し.md` | 教員経験を大学職員の言葉に翻訳する対応表、STARエピソード5本、30秒自己紹介 | 最初に読む。書類作成前 |
| `01_志望動機と自己PR.md` | 志望動機の型、職種別テンプレ（教務／入試広報／国際／キャリア／DX）、自己PR3本、逆質問 | エントリーシート作成時 |
| `02_面接想定問答.md` | 頻出質問への回答案、大学職員特有の質問、直前30分チェック | 面接1週間前〜当日 |
| `03_小論文対策.md` | 800字の型、頻出テーマ12、骨子サンプル3本、時間配分 | 筆記試験前 |
| `04_筆記時事と当日運用.md` | 高等教育キーワード、適性検査、書類チェックリスト、前日・当日運用、心構え | 通しで使う |
| `05_ES回答ストック.md` | ES頻出8設問の完成回答（400字基準・増減方法つき）。大学固有部分だけ差し替える | 書類・ES作成時 |
| `06_応募管理と1校15分リサーチ.md` | 1校15分のリサーチ手順、応募管理台帳の項目、週次の回し方、提出前チェック | 数を出す運用の全期間 |
| `07_マイナビ運用手順.md` | マイナビ各サービスの違い、職種カテゴリでの検索、WEB履歴書設定、併用すべきチャネル | 求人を探す段階 |

## 使う順番

### 数を出す段階（応募先未確定）

1. `00` を読み、翻訳対応表で自分の経験の見え方を切り替える
2. `05` の汎用ESを、200字版・400字版で確定させる（**ここまでは応募先が決まっていなくてもできる**）
3. `06` の「事前準備」を消化する（証明書の取得が最も時間を食う）
4. 以降は、1校あたり `06` の15分リサーチ → `05` の ▼ を埋める → 提出、を繰り返す

### 選考が進んだ段階

5. `01` の職種別テンプレで、志望動機を応募職種に寄せる
6. `03` のテーマから3本、時間を計って手書きで練習
7. `02` を音読。特に「なぜ教員から職員へ」は詰まらずに言えるまで
8. `04` のチェックリストで当日の準備を確定

## 更新ルール

面接で聞かれた質問は、当日中に `02_面接想定問答.md` に追記する。
選考を受けるたびに精度が上がる形で運用する。
