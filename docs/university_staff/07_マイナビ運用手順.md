# 07 マイナビ経由の応募｜チャネル選択と運用手順

## 1. マイナビは1つではない（ここを間違えると求人が来ない）

| サービス | URL | 性質 | 大学職員求人 |
| --- | --- | --- | --- |
| **マイナビ転職** | `tenshoku.mynavi.jp` | 一般転職サイト。**サイトから直接応募** | **○ 職種カテゴリが独立して存在する** |
| マイナビスカウティング | `scouting.mynavi.jp` | **年収600万円以上のハイクラス専用**スカウト | △ ほぼ来ない。大学職員の中途は400〜600万円台が中心のため |
| マイナビ転職AGENT | `mynavi-agent.jp` | キャリアアドバイザー面談型 | ○ 非公開求人あり。面談の手間はかかる |

> **判断**：本命は**マイナビ転職**。スカウティングは登録したまま放置でよい（害はない）。
> エージェントは、書類が固まってから余力で追加する。

---

## 2. マイナビ転職での検索（職種カテゴリを使う。キーワード検索だけに頼らない）

大学職員は**職種カテゴリが独立している**ため、フリーワードよりカテゴリ指定のほうが漏れが少ない。

| カテゴリ | コード | URL |
| --- | --- | --- |
| 大学（学校）職員・事務など | `o1C2` | `https://tenshoku.mynavi.jp/list/o1C2/` |
| 学校法人職員 | `o1C210` | `https://tenshoku.mynavi.jp/list/o1C210/` |
| 東京都・大学（学校）職員 | `p13` + `o1C2` | `https://tenshoku.mynavi.jp/shutoken/list/p13/o1C2/` |

### 検索の設定手順

1. 上記URLで職種を固定する
2. 勤務地を絞る（通勤可能圏。広げすぎると精査に時間を取られる）
3. **この検索条件を保存する**（保存した条件に新着が出たら通知が来る設定にする）
4. 併せてフリーワードでも別に条件を作る：**「学校法人」「大学事務」「教務」「入試広報」「国際交流」**
   - 職種カテゴリが「事務・管理」側に登録されている大学求人を拾うため

### 見るべき欄（求人票で最初に確認する順）

1. **雇用形態**（正職員／契約／嘱託）— 有期なら現職と同じ問題を繰り返すことになる。応募前に判断する
2. **応募資格**（「大学職員経験◯年以上」の縛りがあるか。**未経験可・第二新卒可の表記があるかが最重要**）
3. 掲載終了日（＝実質の締切）
4. 選考フロー（適性検査・小論文の有無）
5. 勤務地（キャンパス移動の有無）

## 3. WEB履歴書の設定（スカウトを受ける側の準備・最優先）

マイナビ転職は、登録した WEB履歴書を見た企業からスカウトが届く。ここを埋めておくと、応募していない大学からも声がかかる。

- [ ] **職務経歴要約**：`職務経歴書_大学職員版` の「職務要約」をそのまま貼る
- [ ] **自己PR**：`05_ES回答ストック.md` 設問2（400字）を貼る
- [ ] **希望職種**：「大学（学校）職員・事務」「一般事務」「総務」あたりを複数選択
- [ ] **希望勤務地**：通勤可能圏を広めに
- [ ] **希望年収**：**高く設定しすぎない**。大学職員のレンジから外れるとスカウト対象から落ちる
- [ ] **保有資格**：英検1級、教員免許を必ず入力（英語力は大学側が明確に評価する項目）
- [ ] **公開設定**：現職に見られたくない場合は、**現在の勤務先をブロック企業に指定**できる。必ず設定する
- [ ] **更新日を新しく保つ**：定期的にログイン・微修正する。更新が新しい登録者は企業の検索で上位に出やすい

---

## 4. 応募の実務

- **応募フォームの「志望動機／自己PR」欄が実質のES**。`05_ES回答ストック.md` の設問1・2を貼り、▼を埋める
- **掲載終了日の直前に応募しない**。企業は掲載期間中に随時選考する。**見つけたら48時間以内**に出す
- 応募後の連絡はマイナビのメッセージ機能に届く。**通知をオンにし、Gmailのフィルタで見落とさないようにする**
- 応募履歴はマイナビ上でも見られるが、**自分の台帳（`06`）に必ず転記する**。サイトをまたぐと管理不能になる

## 5. マイナビだけでは母数が足りない（これは事実として押さえる）

大学職員の中途採用は、**大学の公式サイトでのみ告知されるものが相当数ある**。転職サイトに出るのはその一部。
「片っ端から」を実現するなら、以下を併用する。

| チャネル | 特徴 |
| --- | --- |
| **各大学の公式採用ページ** | 最も確実。**志望度の高い大学は直接ブックマークして巡回する** |
| 大学プレスセンター／私立大学協会系の掲載 | 大学が自ら出す告知が集まる |
| リクナビNEXT／doda／エン転職 | すでに登録済み。**職種で「学校法人」を絞って条件保存する**（現状は条件が合っておらず、無関係な求人しか届いていない） |
| ハローワーク | 国公立大学法人・地方の私大が出すことがある |
| 教育業界特化のエージェント | 学校法人の非公開求人を持っている場合がある |

> **既存の仕組みを流用できる**：日私教研を日次で巡回してスプレッドシートに反映し、自分宛にメール通知する仕組みを既に運用している。
> 巡回先に**志望大学の採用ページ**を追加すれば、大学職員版の求人監視がそのまま作れる。

## 6. スカウティング側の処理（5分で終わる）

- マッチング条件を「教育・スクール・研修」「学校法人」寄りに変更しておく
- ただし**年収600万円以上の求人しか扱わないサービス**であるため、期待はしない
- 通知が邪魔なら配信頻度を落とす。**退会する必要はない**（管理部門の求人が偶発的に有用な場合がある）

## 8. 注意点

- 転職サイトの掲載終了は、**募集終了とは限らない**。志望度が高ければ大学公式を必ず確認する
- 求人票の「未経験可」の有無は最初に見る。**大学職員経験必須の求人に出し続けると、時間だけが溶ける**
- 有期雇用（契約職員）の求人が一定数ある。**現職と同じ不安定さを繰り返さないため、雇用形態は応募前に判断する**
- 同時進行は5校まで（`06` の運用ルール）
