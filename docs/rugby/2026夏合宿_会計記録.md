## 未解決の論点（会計報告書の作成前に決める）

1. **大人4名分の宿泊費 ¥117,350 の負担元**
   宿泊・食事・BBQ・グラウンドの徴収額は¥2,438,170に対し請求は¥2,555,520。
   差額は顧問2名・外部コーチ2名の宿泊食事代。現状は生徒の雑費余剰から
   埋まる形になっている。父母会予算（分類B）から補填する形にするか要検討。

2. **雑費の余剰 ¥254,325 の扱い**
   徴収¥287,000に対し実支出¥32,675（領収書7枚＋ランドリーカード）。
   1人あたり約¥6,055の余り。返金するか部費にプールするか要決定。

3. **予備費 ¥42,000 の返金**
   「未使用の場合は返金」と保護者へ案内済みのため、返金が筋。

4. **コーチ謝礼の支払いと財源**
   コーチの延べ宿泊5人泊分（¥45,850相当）は既にホテル請求に含まれている。
   徴収済みのコーチ費¥40,170では宿泊代だけで不足。謝礼を含めると
   ¥68,000〜71,000程度になる見込み。分類B（父母会予算）から出すか要確認。

5. **バスの追加請求**
   有料道路代・駐車場代が後日実費請求される。これが確定するまで最終決算にならない。

## 手土産の会計分類

東京ばな奈¥6,781と串団子¥3,870（28パック）は対戦校への手土産と思われる。
部のルールでは手土産代は合宿費とは別に父母会予算（分類B）から支出するため、
合宿費の会計に混ぜないこと。合計¥10,651。
※選手の補食だった場合も分類Bだが、費目名は「補食」とする。

## 昨年（2025年度）の様式と前例

Googleドライブ「【05】ラグビー部会計関連」内の
`★2025【夏合宿会計報告】ラグビー部会計報告.xlsx` を解析した結果。
今年度の報告書もこの様式を踏襲すること。

### 昨年の夏合宿会計報告の構成（3シート）

**Sheet1（保護者向け収支報告）**

- ヘッダー: 宛名「ラグビー部保護者各位」／日付／差出人（校長・顧問名）／
  タイトル「ラグビー部夏合宿 収支報告」／挨拶文
- **収入**の費目: 選手参加費／マネージャー参加費／途中参加者1・2／
  **顧問宿泊費・交通費・昼食代**
- **支出**の費目: ホテル宿泊代／増（追加）昼食代／BBQ代／雑費※1／バス代※2／
  グラウンド使用料／**コーチ宿泊代・交通費・謝礼**／
  ○/○帰宅生徒返金分／**予備費未使用返金分**
- 末尾: 収支差額（収入−支出）／バス代差額／**合宿残金※3**
- 注釈で雑費の内訳・バス代の精算ロジック・残金の使途を説明

**合宿中使用経費シート**: 雑費の一次記録。日付／雑費番号／品目／金額。
昨年は **雑費1〜36の36件**。下部でカテゴリ別（ロックアイス・氷、補食費など）に集計。

**合宿中の支出で父母会予算で精算するものシート**: 対戦校手土産・SDカード・
テーピング等、合宿中に立て替えたが父母会予算（分類B）で精算した項目の一覧。

### 前例が示す扱い（未解決だった論点への回答）

| 論点 | 昨年の扱い |
|---|---|
| 顧問の宿泊費・交通費・昼食代 | **収入**に計上。生徒徴収とは別財源から充当している |
| コーチの宿泊・交通費・謝礼 | **支出**の独立費目として計上 |
| 予備費の未使用分 | 支出「予備費未使用返金分」として@¥1,000×41名を返金 |
| 途中帰宅した生徒 | 支出「○/○帰宅生徒返金分」として個別返金 |
| 余った残金 | 「合宿残金」として計上し、**合宿後のプロテイン代等に充当**（返金しない） |
| 対戦校への手土産 | 合宿費に含めず、**父母会予算（分類B）で精算**（別シート管理） |

### 2026年度会計台帳（マスター）での位置づけ

`2026年度ラグビー部会計Excelシート.xlsx`（10シート）では、夏合宿は
**会計分類C（単発会計）**に属する。
「【会計分類C】単発会計」に「夏合宿費用の徴収」「夏合宿バス手配と費用の振込」の
行があり、「【会計分類C】振込履歴」に実際の送金記録が入る。
A・B台帳の末尾には「夏合宿、春合宿残額」の集計行があり、合宿の残額が
年度全体の残高に合流する構造。個人立替精算シート（畠山立替分など）も存在する。
