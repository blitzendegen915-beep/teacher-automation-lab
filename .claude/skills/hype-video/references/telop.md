# テロップと文字演出の型

実際のイベントトレーラーをコマ単位で観察すると、
「太字＋黒フチをドンと出す」というよくある作り方とは違う型が使われている。
ここではその型を整理する。

## 大原則：文字は少ないほど強い

画面が説明的になるほど、かっこよさは落ちる。
2分の動画に入れる文字は、**タイトル・キャッチコピー・情報・締め**の4種で足りる。
選手紹介などを入れる場合も、1人あたり1〜2語に絞る。

## 型1：キャッチコピーを出しっぱなしにする

**一番効く。** 短いテロップをパッパッと出すより強い。

- キャッチコピー1つを **3秒前後** そのまま画面に出す
- その **下で映像を5〜10カット切り替える**
- 文字はゆっくり一定速度で流す（縦に150px程度、全体で3〜6%わずかに拡大）

文字が動かず映像だけが変わるので、言葉に重みが出る。
`assets/telop_drift.anm` がこの動きを作る。等速（イージングなし）が基本。

配置は画面の中央付近。映像が明るいカットに重なっても読めるよう、
うっすら影を落とすか、下のレイヤーに黒の薄いグラデーションを敷く。

## 型2：小さいラベル＋大きい値

情報を出すときの定番。**2行組**にする。

```
場 所                    ← 小さく、字間を広めに
所沢くすのきホール          ← 大きく
```

```
DAY1                     ← 小さいラベル
1530-192                 ← 大きい数字
```

- 上のラベルは本文の **1/3〜1/4のサイズ**、字間を広く取る
- 下の値は大きく、**細めのウェイト**
- 左揃えで、画面の下1/3あたりに置く
- フチ取りは付けない。暗い映像に白文字を置くだけで成立する

数字はハイプ動画と相性がいい。参加人数、連勝記録、スコア、部員数、
創部からの年数など、**具体的な数字を1つ出すだけで説得力が変わる。**

## 型3：極小のクレジットを出しっぱなしにする

画面の隅に、担当者名やメンバー名を **本文の1/5程度の極小サイズ**でずっと出しておく型。
読ませるためではなく、情報密度で「作り込んだ感」を出すための装飾。

部活動なら、部員名簿・スタッフ・マネージャー名などをこの形で使える。
ただし **氏名は個人情報**なので、公開範囲の同意が取れている場合に限る。
不安ならニックネームか背番号にする。

## 型4：締めの情報ストリップ

最後のカードは、横一列に区切って情報を並べる。

```
────────────────────────────────
        大 会 名 / チーム名（極太・大きく）
────────────────────────────────
キャッチコピー │ 日付      │ 人数     │ 場所
Catch phrase   │ 11.2-11.3 │ 30       │ 会場名
                              Players
```

- 上下に**細い罫線**を引くと一気に締まる
- 縦の罫線で区切り、各区画は2行組（日本語＋英語、または値＋単位）
- ここだけは **極太の字体**を使ってよい

## 字体の選び方

| 用途 | ウェイト | 備考 |
| --- | --- | --- |
| タイトル・締めのロゴ | 極太 | ここだけ太くする |
| キャッチコピー | 太〜極太 | フチなし、影は薄く |
| 情報（場所・日付） | 細〜中 | フチなし。暗い映像に白で置く |
| 極小クレジット | 細 | 読ませない前提 |

- 標準環境なら **メイリオ**、無料なら **Noto Sans JP（源ノ角ゴシック）**
- 数字・アルファベットは **縦長のサンセリフ**にすると引き締まる
- 白は純白（#FFFFFF）より、**わずかに暖色寄りの白**のほうが映像になじむ

### フチ取りをいつ付けるか

背景が明るい・雑然としている場合だけ。黒フチ2〜4px。
**暗い映像に置くなら付けないほうが上品。** 実際のトレーラーはフチなしが主流で、
その代わり文字を置くカットを暗いものから選んでいる。

## テロップを出すタイミング

音ハメしている動画なら、テロップの開始位置もビートに合わせる
（`assets/beatgrid.html` でフレーム番号を出す）。
音ハメしていない動画なら、**映像の見せ場より0.2秒ほど早く**出すと自然に見える。

## 短く出すテロップの動き

`assets/telop_kick.anm` を使う。行き過ぎてから戻る動き（オーバーシュート）。

| 項目 | 目安 |
| --- | --- |
| 入り時間 | 0.25〜0.4秒。短いほど鋭い |
| 移動量 | 60〜120px。マイナスで上から |
| 跳ね | 60〜100。バネ感 |
| 出時間 | 0.2〜0.3秒 |
