# 撮影の設計

編集で盛れる量は素材で決まる。ここでの判断は後から取り返せないので、
**編集の話より先に撮影の話をする。**

## カメラ設定

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| フレームレート | 60fps。スローにするカットは120fps以上 | 30fpsで撮るとスローにできない |
| シャッタースピード | fps の約2倍（60fps→1/120、120fps→1/240） | 遅すぎるとブレ、速すぎるとパラパラして安っぽい |
| 解像度 | 1920×1080 で十分。4K なら寄りの余地が増える | 1080p60 のほうが編集が軽い |
| 手ブレ補正 | オン | 動きながら撮るなら必須 |
| 時間帯 | 夕方の斜光か曇り | 昼の順光が一番かっこよく撮れない |
| 向き | 横。縦動画用なら別に撮る | 1本を両方に使い回すと構図が壊れる |

スマホでも撮れる。iPhone なら「ビデオ」を60fps、スローが要るところは
「スロー」モード（120/240fps）で撮る。

**スローにしたいカットだけは、撮影時から120fps以上にする。** これだけは編集で作れない。

## 撮るべきカット

**同じ場面を違うアングルで2回以上**撮るのが基本。編集はアングルの切り替えで成立する。
最低でも、寄り・引き・ロー（地面すれすれ）の3種を意識する。

### 動きのカット

競技や題材によって中身は変わるが、狙いは共通している。

- **ぶつかる瞬間**（タックル、スクラム、当たり）
- **決まる瞬間**（得点、成功、勝敗が動く瞬間）
- **速度が出ている場面**（走る・突破する。並走しながら撮ると迫力が出る）
- **道具が動く瞬間**（ボールが手を離れる、ラケットが当たる、足がボールを捉える）
- **リアクション**（決めた直後、ベンチ、観客）

### 間を作るカット

**これが足りないと、どれだけ速く切っても単調になる。** 動きのカットと同じくらい重要。

- 手元（靴紐を結ぶ、道具を握る、テーピングを巻く）
- 表情（息が上がっている、汗、目線）
- 円陣、肩を組む背中
- 水をかぶる、タオルで顔を拭く
- 誰もいない会場・グラウンド・器具（冒頭と最後に使う）
- 準備の風景（設営、荷解き、ウォームアップ）

参考にしたトレーラーの多くは、**競技そのものの映像と、人の映像を交互に混ぜている。**
競技だけを並べると記録映像になり、人だけだとドキュメンタリーになる。混ぜると「作品」になる。

### 枚数の目安

完成2分の動画に対して、素材は **30〜60カット**。
うち3割は「間を作るカット」に充てる。

## やりがちな失敗

- **ズームしながら撮る** … デジタルズームは画質が落ち、編集で使いにくい。自分が動く。
- **1カットを長く撮りすぎる** … 5〜8秒で切って、別アングルで撮り直すほうが使える。
- **全部を引きで撮る** … 寄りがないと迫力が出ない。
- **上下に余裕を持たせない** … レターボックスを入れると顔や足元が切れる。
- **明るい昼だけで撮る** … 色味を作る余地がなくなる。全カットを同じ時間帯に撮ると色合わせは楽になるが、
  順光の昼だけは避ける。

## 撮影前にユーザーに確認すること

- 使う曲は決まっているか（決まらないとカットの長さも構成も決まらない）
- 完成尺の希望（1分30秒〜2分30秒を勧める）
- どこで公開するか（校内上映のみか、インターネット公開か。権利の扱いが変わる）
- 写る人の同意は取れているか
