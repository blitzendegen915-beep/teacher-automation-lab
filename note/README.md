# note 記事の生産ライン

note（https://note.com/human_willet5936）で有料記事を継続的に出すための作業場所です。

## 方針

このアカウントの強みは「現役の高校英語教員が、実際に動くものを作って使っている」ことです。
note にはノウハウ記事が大量にありますが、**動く成果物（コード・テンプレート・PDF）が丸ごと付いてくる記事**は多くありません。ここで差をつけます。

したがって、有料記事は次の形を基本にします。

> 無料パート：課題 → 何ができるようになるか → 仕組みの説明 → やってみた結果
> 有料パート：**そのままコピペして使える成果物の全文** ＋ 設置手順 ＋ つまずきどころ ＋ 応用

「考え方だけ」を有料にしない。読者が金を払うのは**時間の節約**であって、感想ではありません。

## ディレクトリ

| 場所 | 中身 |
| --- | --- |
| `note/backlog.md` | ネタ出しリスト。書く前にここから選ぶ |
| `note/style-guide.md` | **AIが書いたと思われない日本語にする直し方** |
| `note/tools/ai-check.js` | 原稿の「AI臭」を機械的に拾うチェッカー |
| `note/templates/paid-article.md` | 有料記事のひな型 |
| `note/drafts/` | 執筆中・完成した原稿（Markdown） |

## AI原稿を直す

ChatGPT等に下書きを書かせた場合は、公開前に必ず通します。

```
node note/tools/ai-check.js note/drafts/001-google-forms-quiz-generator.md
```

複数まとめて見るなら `node note/tools/ai-check.js note/drafts/*.md` です。
指摘の直し方は `note/style-guide.md` にまとめてあります。

AI臭は語彙より**リズムと構造**から出ます。単語を言い換えるだけでは消えません。
詳しくはスタイルガイドを読んでください。

## 執筆から公開までの手順

1. `note/backlog.md` からネタを1本選び、ステータスを `執筆中` にする。
2. `note/templates/paid-article.md` をコピーして `note/drafts/NNN-スラッグ.md` を作る。
3. 原稿を書く。無料パートと有料パートの境界は `<!-- ===== ここから有料 ===== -->` で示す。
4. note のエディタに貼る。Markdown の見出し（`##`）と箇条書きはそのまま貼れば note 側で整形されます。**表組みは note が対応していないので、箇条書きに崩すか画像にする。**
5. 有料ラインを設定し、価格を付ける。
6. 公開したら `backlog.md` に URL と公開日を書き戻す。

## 価格の付け方

| 種類 | 目安 | 理由 |
| --- | --- | --- |
| 手順＋コード全文つき | 500〜980円 | 読者が自分で作れば数時間。時給換算で確実に得 |
| 実録・体験談（成果物なし） | 無料 or 300円 | 単体では弱い。集客に回す |
| テンプレート配布つき | 500〜1,500円 | ファイルの価値がそのまま価格になる |
| まとめ・総集編（マガジン） | 単品合計の6〜7割 | 既存記事を束ねるだけなので原価ゼロ |

最初の3本は **500円** で揃えるのがおすすめです。価格を迷う時間が一番もったいない。

## 伸ばし方の基本

- **無料記事と有料記事を交互に出す。** 無料記事だけでは売上が立たず、有料記事だけではフォロワーが増えません。目安は無料2：有料1。
- **無料パートを長めに取る。** note は購入前に無料部分しか読めません。無料部分が短いと「中身が分からないもの」に金を払うことになり、そこで離脱します。全体の4〜5割は無料で見せる。
- **1本目の冒頭3行で刺す。** note のタイムラインではタイトルと冒頭しか見えません。
- **記事の末尾から教材ストアに送る。** `https://blitzendegen915-beep.github.io/edusup` へのリンクを全記事の最後に置く。逆にストア側からも note に送る。
- **シリーズにする。** 単発より「全5回」のほうが次を読まれます。

## やらないこと

- 生徒・保護者・同僚が特定できる情報は、ぼかしても書かない。
- 勤務校名、地域、学校の内部事情は書かない。
- 教科書や市販教材の本文をそのまま載せない（引用の範囲を超える）。
- 成績データ等は必ずダミーで載せる（`AGENTS.md` の方針と同じ）。
